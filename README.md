# 渡夜手册

《艾尔登法环：黑夜君临》的非官方离线资料工具。黑环攻略的本地集成，AI 辅助整理与开发；资料来自社区，核验范围和未决差异随数据保留。

**最新正式版本：v0.5.0 · 数据快照：2026.10.17-r1 · Android 8.0 及以上。**

支持词条分组与档位比较、局内/局外分类、夜王属性、两夜 Boss 反查、大空洞水晶点位、角色和技能、事件、收藏、历史记录及显示设置。全部查询资料随本地网页或 APK 携带，应用不申请网络与存储权限。

## v0.5.0 新增功能

武器图鉴提供 **387 件装备目录 / 33 种类别 / 25 件传说武器**。42 件含来源示例面板，345 件先收录名称与分类；传说武器均可查面板、战技与原有庇佑。支持搜索、分类与品质组合筛选、收藏、最近查看和每批36件加载。武器名称优先展示，类别缩为小字；空防御、空异常等不显示，来源说明集中在条目末尾。

后续交付以Android手机版App为准，电脑用于预览与开发。

新增**缩圈倒计时**：首页、侧栏及顶部均可进入，采用紧凑数字与四格时间轴，校准区按需展开；支持两夜分别启动、选择本夜开始/首次缩圈开始/首次缩圈结束/第二次缩圈开始作为起点、暂停、重置、±30秒和输入已过时间校准。刷新或切出后按真实经过时间恢复；正文以约14:00作为末次结束提醒，14:30的来源差异在末尾说明。

正式 APK 沿用既有包名、签名和存储键，支持覆盖 v0.4.1。电脑正常启动使用4317；独立预览使用4318、`duye-weapons-preview-v1:`存储前缀和独立离线缓存，便于测试而不改动正式记录。

面板均为可追溯的网页示例，未完成现版游戏、强化及角色条件核验。目录按2025年基础装备资料整理，未声称包含后续DLC初始装备；v0.5.0发布时有345件待补面板，当前预览已补齐来源记录。原11个候选中文名状态、原始观察及来源冲突在详情末尾保留。

## 当前未发版预览

独立预览已将武器面板覆盖从42件补至387件，数据快照为 `2026.10.18-r3-preview`。原24个待核数值补入23个，43件盾牌品质已补；黑夜骑兵连枷防御强度21/32继续待核。传说品质筛选26件，原25条庇佑关联保留。旧样本完整保留，版本/强化/角色条件未核实，不提供强弱排名。上述变化尚未进入正式APK。

2026-10-28在本地 `feat/voice-query-preview` 分支加入**语音查询电脑测试版**：轻量中文模型、Vosk中文小模型及同段录音对照；支持武器、词条、角色、夜王等名称查询，以及简称、同音字候选、局内/局外和档位筛选。原始转写与候选并列，点击候选进入原详情；不修改游戏数据。手机端语音引擎尚未接入，应用版本仍为0.5.0。

本机已装好语音环境，双击 **`打开语音测试.cmd`**，或打开 <http://127.0.0.1:4318/#voice>。首次点击麦克风时允许浏览器录音，停顿后自动查询；“同段对照”用同一段声音测试两个模型。“试试简称”只测试文字匹配。录音仅在本机内存处理，不保存录音或转写，不调用云端识别。

换电脑时先安装Python 3.12，再运行 `./Start-VoicePreview.ps1 -Setup` 下载依赖与两种模型。后续可断网启动；普通 `npm start` 仅提供网页，不能运行语音识别。环境、大小、测试范围和手机接入前置条件见 [语音预览维护](docs/DEVELOPMENT.md#语音查询电脑预览2026-10-28)。

后续方向仅记为候选，顺序与范围见 [开发计划](docs/DEVELOPMENT.md#候选开发方向2026-10-17)。本轮不发布新版。

## 直接看效果

电脑安装 Node.js 22 或以上后，在此目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:4317/#home>。不需要 `npm install`，没有运行时 npm 依赖。Windows 也可双击 `打开渡夜手册.cmd`，打开独立4318预览。电脑默认以390px手机界面预览，可用“展开预览”临时检查宽屏，改完刷新即可；不需要每次安装 APK。无 Node 时，可直接打开 `dist/index.html`。

这是本机预览地址。手机可直接下载 [v0.5.0 APK](https://github.com/Toramy404/duye-handbook/releases/download/v0.5.0/duye-handbook-v0.5.0.apk)，更新说明和 SHA-256 见 [正式发布页](https://github.com/Toramy404/duye-handbook/releases/tag/v0.5.0)；以后从 [最新版本入口](https://github.com/Toramy404/duye-handbook/releases/latest) 下载。已装旧版请直接覆盖安装，详见 [安卓说明](android/README.md)。APK 不写入 Git；本机安装包 `release/duye-handbook-v0.5.0.apk` 与公开附件内容一致，历史包保留。

Python 需 3.10 或以上。CI 会运行相同检查，并编译不含发布签名的 Android 包。它不代替手机安装、覆盖升级、断网、返回退出和导出测试。

## 目录

| 目录 | 用途 |
| --- | --- |
| `dist/` | 直接运行的网页源码、生成的数据包与离线图片；本项目没有前端编译框架 |
| `data/` | 可维护的 JSON 数据源、来源、纠错和疑问记录 |
| `android/` | Android WebView 宿主、资源和版本号 |
| `scripts/`、`tests/` | 数据生成、构建与回归检查 |
| `config/voice-aliases.json` | 人工维护的语音简称；派生发音索引不修改游戏资料 |
| `.github/` | 自动检查、问题表单和合并说明模板 |
| `docs/` | 维护办法 |
| `release/` | 本机安装包，Git 只收录说明；公开安装包应放 Releases |

## 已验证和待确认

873 条效果原记录按场景形成 722 个入口，保持原有 617 个同名组的对应关系。分组只组织显示，不重算数值，不为无编号记录猜测档位。

520 种地图配置的两夜主要 Boss 已跨表核对；词条仍有 294 条未完成第二来源逐项语义验证，部分角色属性来源仍有差异。详情保留条件、来源与待核验说明。资料快照日期不是游戏版本，普通/深夜/永夜数据不能互换。

v0.5.0 沿用既有包名与签名，以已发布 v0.4.1 APK 为覆盖升级基线，versionCode 为500。构建检查签名、版本递增、离线资源和正式存储兼容；真机验收与来源待核项在发布说明中保留。正式标签指向实际构建提交，已发布附件不覆盖。
